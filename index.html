BYTE//CROWN FIELD GUIDE

BYTE//CROWN is a complete byte-native stored-program computer. Every instruction cell keeps the original grammar O DDDDDD A. When O=0, the middle six bits are literal data and A chooses PUSH6 or LOAD6. When O=1, the middle six bits select one of 64 operator slots and A selects its paired action.

Machine anatomy

  • 64 KiB unified byte memory, addressed by two independent address bytes.
  • 16 general 8-bit registers, eight 1-bit flags packed into one status byte, byte-pair PC/SP/MAR, byte IR/MDR, and a four-byte clock.
  • 128 base operator actions, 64 extension actions, plus 128 directly executable data-plane bytes.
  • Memory stack, calls, interrupts, 16 vectors, conditional branches, integer and bit ALU, strings, arrays, device I/O, deterministic random source, audio, and a byte-color framebuffer.

Assembler

Numbers accept decimal, $FF, 0xFF, 0b1111, and character literals. Registers are R0–R15, with aliases A B C D E F X Y SI DI BP T0 CX TMP. Memory operands use brackets. The assembler supports labels, expressions, .org, .entry, .equ, .byte, .word, .text, .asciz, .fill, .align, and .vector.

Friendly pseudo-forms such as MOV R0,#42, MOV R0,[label], MOV [label],R0, ADDI, CLR, TST, PRINT "text", JE, and HALT lower into real byte instructions. R15/TMP is the documented scratch register for immediate ALU pseudos.

Memory map

$0000–$EFFF general RAM · $F000–$F0FF framebuffer · $F100–$F10F port mirror · $FFE0–$FFFF sixteen interrupt vectors. Reset stack begins at $FFDF; default code origin is $0200.

Debugging

Click a memory byte or register to move it into the Living Byte Lens. Toggle its individual bits, perform wrapped byte arithmetic, write it back, or execute it directly. The disassembler tracks instruction boundaries. Breakpoints pause before execution. The stack, flags, bus latches, terminal, screen, trace, and memory all update live.
